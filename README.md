# Quick Start

```bash
git clone https://github.com/FaceWithDark/VOS.git   # HTTPS method
git clone git@github.com:FaceWithDark/VOS.git       # SSH method

docker compose up --build -d
```

Access landing page at [localhost:8001](http://localhost:8001/)
